LUMEN in the browser

A 290 KiB WebAssembly build of the same codec the CLI uses. Drop a .lum file to decode it, or drop a PNG/JPEG to encode one — pixel-for-pixel identical to lum encode and lum decode.

Drop an image
.lum to decode · PNG/JPEG/WebP to encode

import { Lumen } from "./lum.js";
await Lumen.init();

const image = Lumen.decode(await (await fetch("photo.lum")).arrayBuffer());
canvas.getContext("2d").putImageData(Lumen.toImageData(image), 0, 0);

// or, the other way round
const bytes = Lumen.encode(ctx.getImageData(0, 0, w, h), { quality: 90 });

Or just use the element: <lum-img src="photo.lum">

Everything here runs locally. The file never leaves the tab; the numbers below are measured in this page. Serve it over HTTP (python3 -m http.server) so the browser may fetch lum.wasm.
